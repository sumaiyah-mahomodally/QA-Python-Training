# Module 5 - Objects: Modeling Tasks as Real Things

## Topics Covered

- Classes
- Objects
- Methods
- Constructors (__init__)
- Serialization
- Deserialization
- Refactoring to Objects

## Files

### task_manager_v5.py
Task Manager using Task objects instead of dictionaries.

### exercise_2_task_object_demo.py
Demonstrates:
- Creating objects
- __str__()
- mark_complete()
- to_dict()
- from_dict()

### tasks.json
Stores task data.
